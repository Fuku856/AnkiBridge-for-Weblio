# AnkiBridge for Weblio

[Weblio学習](https://weblio-study.weblio.jp/) の単語トレーニングを解き終えたとき、結果画面の「出題リスト」から英単語と日本語訳を読み取り、Anki に自動で登録する Violentmonkey 用ユーザースクリプトです。

結果画面のスクリーンショットを AI に渡して CSV を作り、Anki に取り込む手間がなくなります。

## 必要なもの

- [Violentmonkey](https://violentmonkey.github.io/)（ブラウザ拡張）
- [Anki](https://apps.ankiweb.net/)（PC版）
- AnkiConnect アドオン（コード `2055492159`）

## インストール

1. **AnkiConnect を入れる**
   Anki で「ツール → アドオン → アドオンを取得」を開き、`2055492159` を入力して Anki を再起動します。
2. **スクリプトを入れる**
   Violentmonkey のダッシュボードで「+ → 新規作成」を選び、`AnkiBridge-for-Weblio.user.js` の中身を貼り付けて保存します。
3. **接続を確認する**
   Anki を起動したまま Weblio学習を開きます。Violentmonkey のメニューから「設定を開く」を選び、「接続テスト」を押してください。「接続OK」と出れば準備完了です。

## 使い方

1. Anki を起動しておきます（登録には AnkiConnect が動いている必要があります）。
2. Weblio学習で単語トレーニングを最後まで解きます。
3. 結果画面が表示されると、画面右下にパネルが出て単語が Anki に登録されます。
   - 自動モード（既定）では、結果画面が出た時点で登録されます。
   - ボタンモードでは、パネルの「Ankiに登録」を押したときだけ登録されます。
   - 同じデッキに同じ英単語がすでにある場合は登録せず、スキップした数を表示します。

カードは **表 = 英単語、裏 = 日本語訳** で作られます。日本語から英語を選ぶ問題でも同じ向きになります。

## 設定

パネルの ⚙ ボタン、または Violentmonkey のメニュー「設定を開く」から変更できます。

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| 登録モード | 自動で登録 | 「ボタンを押して登録」に切り替えられます |
| 登録対象 | 全問 | 「間違えた単語のみ」「正解した単語のみ」も選べます |
| デッキ名 | `Weblio` | ない場合は自動で作成されます |
| ノートタイプ | `基本` | 日本語版 Anki の標準ノートタイプです |
| 表 / 裏のフィールド | `表面` / `裏面` | ノートタイプのフィールド名です |
| タグ | `weblio` | スペース区切りで複数指定できます |
| トレーニング名をタグに追加 | ON | 例: `英検3級対策単語1` |
| AnkiConnect URL | `http://127.0.0.1:8765` | 通常は変更不要です |

英語版の Anki を使っている場合は、ノートタイプを `Basic`、フィールドを `Front` / `Back` にしてください。「Ankiから候補を取得」を押すと、Anki にあるデッキ・ノートタイプ・フィールドを入力候補に表示します。

## トラブルシュート

- **「AnkiConnectに接続できません」と出る**
  Anki が起動しているか、AnkiConnect が有効になっているかを確認してください。初回はブラウザ拡張から Anki への通信許可を求められることがあります。Violentmonkey の確認画面で許可してください。
- **「ノートタイプ『基本』がAnkiにありません」と出る**
  設定でノートタイプ名とフィールド名を、Anki 側の名前に合わせてください。
- **結果画面でパネルが出ない**
  対象は単語トレーニング（「Question n」「あなたの解答」「正解」が並ぶ結果画面）だけです。リスニングや会話などのトレーニングでは表示されません。
- **自動モードで同じ結果を登録し直したい**
  パネルの「Ankiに登録」を押すと、何度でも登録できます（重複はスキップされます）。
